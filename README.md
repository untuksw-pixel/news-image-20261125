# The World Today — Wednesday 25 November 2026

A single dense front page summing up Wednesday 25 November 2026's world news: 42 dated stories across 8 regions and 10 fields — from the US proposing tariffs on 14 economies and the Strait of Hormuz tanker attacks to Shenzhou-24 docking with Tiangong and the Pope's lament over the failed COP31 talks — organised by region with a UTC timeline strip and a date-check audit line at the foot. Every story on the page happened or was first reported on 25 November 2026, checked against that day's wire reports.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) decodes the image and writes `out/entry.png`. The image ships in this repository as `entry.png.b64` — the PNG's bytes base64-encoded into a single-line text file, because the snapshot channel carries text only.
